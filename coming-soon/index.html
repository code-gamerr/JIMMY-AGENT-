The model layer

It talks. It sees. It speaks back.

Not a chat box with a model glued on. Jimmy can hear you, look at what you paste, generate media, and switch models without a rewrite.

Voice

Hey Jimmy

On-device wake word on CLI, TUI, and desktop. Talk in the terminal or a Discord voice channel. Replies can be spoken; voice memos on messaging get transcribed.

Vision

Paste a frame

Drop an image into the CLI and any vision model can read it. The same path covers screenshots, diagrams, and whatever the browser just opened.

Generate

Image, video, speech

Image and video generation tools, plus TTS across Edge, ElevenLabs, OpenAI, and local voices. The agent makes the asset, then keeps working.

Route

Pick the brain

Azure Foundry, OpenRouter, OpenAI, or a local endpoint. Sort by cost or quality, fail over, rotate keys. Aux tasks like vision and compression can use a different model.

Learn

Skills write themselves

After a hard task Jimmy can write a skill, then load it later. Memory stays curated. Session search recalls old work instead of starting blank.

Split

More than one model at once

Subagents run isolated jobs in parallel. A Python script can call Jimmy tools over RPC so a long pipeline is one turn, not a dozen.
